# 엑스트라 무제한 문구 DB 보정 절차

## 배경

- 일부 카드는 일본어 본문(`card_texts_ja.effect_text`)에만
  `このホロメンはデッキに何枚でも入れられる` 문구가 있고,
  한국어 본문(`card_texts_ko.effect_text`)에는 대응 문구가 없습니다.
- 앱 규칙은 이미 ko/ja 둘 다 검사하도록 보강할 수 있으므로 즉시 동작은 보장됩니다.

## 단기 대응 (권장, 즉시 적용)

1. 앱 규칙에서 ko/ja 패턴을 함께 판정합니다.
2. DB는 수정하지 않아도 덱 규칙 동작은 유지됩니다.

## 중기 대응 (데이터 품질 보정, 선택)

### 1) 누락 카드 점검

```bash
python3 tools/check_extra_unlimited_texts.py --limit 100
```

- 필요 시 카드 번호 목록만 추출:

```bash
python3 tools/check_extra_unlimited_texts.py --list
```

### 2) 보정 방식 선택

- **A안: 크롤러 보정**
  - 크롤링 시 ja 본문의 `何枚でも` + `入れられる` 패턴을 감지
  - ko 본문이 비어 있으면 표준 문구 추가
- **B안: DB 패치 스크립트 보정**
  - 누락 카드만 SQL `UPDATE`로 보정
  - 기존 본문이 비어 있지 않다면 줄바꿈 후 문구를 덧붙이는 방식 사용

표준 한국어 문구:

`엑스트라 이 홀로멤은 덱에 몇 장이라도 넣을 수 있다.`

### 3) 검증

1. 보정 후 `tools/check_extra_unlimited_texts.py` 재실행
2. `ja only` 누락 카드 수가 기대값(0 또는 허용치)인지 확인
3. `hBP04-020` 같은 기준 카드의 ko/ja 상태 확인

## 배포 주의사항

- DB 파일은 앱 번들이 아니라 GitHub Release `DB` 태그로 배포합니다.
- DB 수정 시 앱 코드 릴리스와 별개로 DB 릴리스 버전만 갱신합니다.
