Privacy Policy / 개인정보 처리방침

Last Updated: February 2026

🇺🇸 English

hOCG_H ("the App") is designed as a lightweight search utility for publicly available Hololive OCG card information.

1. Personal Information

The App does NOT collect, store, process, transmit, or share any personal information.

Specifically:

  • No account registration
  • No login system
  • No user profiles
  • No analytics or tracking
  • No advertising identifiers (e.g., IDFA)
  • No device fingerprinting
  • No background data collection

The App does not request access to contacts, location, camera, microphone, photos, or any sensitive permissions.

2. Network Communication

The App may connect to publicly accessible GitHub repositories to:

  • Check for database updates
  • Download a read-only database file
  • Download publicly available card images

These requests:

  • Do not include any personal data
  • Are not tied to any individual user
  • Are not used for tracking or analytics

No personal information is transmitted to any external server.

3. Local Storage

The App may store downloaded database files and images locally on the user's device for offline viewing.

This data:

  • Remains entirely on the user’s device
  • Is not shared externally
  • Can be removed by deleting the App

4. Third-Party Services

The App uses GitHub solely as a public file hosting service.

The App does not share user data with GitHub or any third party.

Users are subject to GitHub’s own privacy policy when accessing GitHub-hosted resources.

5. Children’s Privacy

The App does not knowingly collect any personal information from children or any users.

6. Changes to This Policy

This Privacy Policy may be updated if the App’s functionality changes. Any updates will be reflected on this page.

7. Contact

For any privacy-related questions, contact:

perlihite@gmail.com

🇰🇷 한국어

hOCG_H(이하 "앱")은 공개적으로 제공되는 홀로라이브 OCG 카드 정보를 검색하기 위한 유틸리티 앱입니다.

1. 개인정보 수집 여부

본 앱은 어떠한 개인정보도 수집, 저장, 처리, 전송, 공유하지 않습니다.

구체적으로:

  • 회원가입 기능 없음
  • 로그인 기능 없음
  • 사용자 프로필 없음
  • 분석 및 추적 기능 없음
  • 광고 식별자(IDFA 등) 사용하지 않음
  • 기기 지문 수집 없음
  • 백그라운드 데이터 수집 없음

앱은 연락처, 위치, 카메라, 마이크, 사진 등 민감한 권한을 요청하지 않습니다.

2. 네트워크 통신

본 앱은 아래 목적을 위해 GitHub 공개 저장소에 접속할 수 있습니다:

  • 데이터베이스 업데이트 확인
  • 읽기 전용 데이터베이스 파일 다운로드
  • 공개 카드 이미지 다운로드

해당 요청은:

  • 개인정보를 포함하지 않으며
  • 특정 사용자와 연결되지 않으며
  • 추적 또는 분석 목적으로 사용되지 않습니다

개인정보는 어떠한 외부 서버로도 전송되지 않습니다.

3. 로컬 저장

앱은 오프라인 열람을 위해 데이터베이스 파일 및 이미지를 사용자 기기에 저장할 수 있습니다.

해당 데이터는:

  • 사용자 기기 내부에만 저장되며
  • 외부로 공유되지 않으며
  • 앱 삭제 시 제거됩니다

4. 제3자 서비스

본 앱은 GitHub를 공개 파일 호스팅 용도로만 사용합니다.

앱은 GitHub 또는 기타 제3자에게 사용자 개인정보를 전송하지 않습니다.

GitHub에 접속하는 경우 GitHub의 자체 개인정보 처리방침이 적용될 수 있습니다.

5. 아동의 개인정보

본 앱은 아동을 포함한 어떠한 사용자로부터도 개인정보를 수집하지 않습니다.

6. 정책 변경

앱 기능이 변경될 경우 본 개인정보 처리방침이 업데이트될 수 있으며, 변경 사항은 본 페이지에 반영됩니다.
